# AI-Based Smart Complaint Management System

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- OpenRouter AI API

## Features
- Complaint Registration
- Complaint Tracking
- AI Complaint Analysis
- Complaint Filtering
- Search by Location
- JWT Login & Signup
- AI Priority Detection
- AI Department Recommendation
- AI Auto Response
- MongoDB Atlas Integration

## Installation

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
